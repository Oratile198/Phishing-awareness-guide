# Phishing Awareness Guide

A short resource that helps non-technical staff recognise, avoid and report phishing emails. Created as a Junior Cybersecurity Analyst mini-project.

## Why this project?
Phishing is one of the most common ways attackers steal passwords and money. Most attacks succeed because someone clicks a link by mistake, so awareness is the first line of defence.

## What is inside
| Folder | File | Purpose |
|--------|------|---------|
| guide | spotting-phishing.md | Explains common phishing red flags and what to do |
| checklist | phishing-checklist.md | Quick checks to run before clicking anything |
| templates | report-suspicious-email.md | Incident-reporting template for the security team |

## How to use it
1. Read the guide to learn the warning signs.
2. Use the checklist whenever an email looks suspicious.
3. If you think an email is phishing, fill in the report template and send it to your IT or security team.
