# Phishing Quick-Check Checklist

Use this checklist before you click a link or open an attachment.

## Check the sender
- [ ] Do I know this sender?
- [ ] Does the email address match the real company domain?
- [ ] Was I expecting this email?

## Check the message
- [ ] Does it create panic or urgency?
- [ ] Does it ask for a password, PIN or bank details?
- [ ] Are there spelling or grammar mistakes?
- [ ] Is the greeting generic, like "Dear customer"?

## Check links and attachments
- [ ] Does the link address match the company website when I hover over it?
- [ ] Is the attachment unexpected (.zip, .exe, .docm)?

## If anything looks wrong
- [ ] Do not click or reply
- [ ] Report it to the IT or security team
- [ ] Delete the email
